# Landmark Classification

This project trains image classifiers to recognize landmarks from a 50-class subset of the Google Landmarks Dataset v2. It includes a convolutional neural network built from scratch, a ResNet50 transfer-learning workflow, and a small Jupyter widget for classifying uploaded images.

## Project structure

```text
.
|-- app.ipynb                 # Interactive image upload and classification demo
|-- cnn_from_scratch.ipynb    # Train and export the custom CNN
|-- transfer_learning.ipynb   # Train and export the ResNet50 classifier
|-- requirements.txt          # Project's Python dependencies (except PyTorch)
|-- src/
|   |-- data.py               # ImageFolder datasets and data loaders
|   |-- helpers.py            # Dataset download and image statistics
|   |-- model.py              # Custom CNN
|   |-- optimization.py       # Loss and optimizer setup
|   |-- predictor.py          # Preprocessing and inference wrapper
|   |-- train.py              # Training, validation, and test loops
|   `-- transfer.py           # Transfer-learning model setup
|-- landmark_images/          # Downloaded dataset (created on first setup)
`-- checkpoints/              # Trained weights and TorchScript exports
```

The `landmark_images` and `checkpoints` folders, along with `mean_and_std.pt`, are generated locally and are excluded from version control.

## Setup

Use a Python version supported by the PyTorch build you choose. PyTorch and TorchVision are required by the source code but are not listed in `requirements.txt`; install a compatible pair for your operating system and CPU/GPU using the [official PyTorch installation selector](https://pytorch.org/get-started/locally/).

Create and activate a virtual environment, then install the project dependencies:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python -m pip install jupyterlab
```

Install `torch` and `torchvision` using the command generated by the [official PyTorch installation selector](https://pytorch.org/get-started/locally/) for your operating system and compute platform. This ensures the pair matches your CPU/GPU setup. On macOS or Linux, use the equivalent virtual-environment activation command for your shell.

Start JupyterLab from the repository root so the relative dataset and checkpoint paths resolve correctly:

```bash
jupyter lab
```

## Dataset

The training notebooks call `setup_env()` from `src/helpers.py`. On first run it downloads and extracts the dataset into `landmark_images/`, computes per-channel image means and standard deviations, and creates the `checkpoints/` directory. The helper caches the statistics in `mean_and_std.pt` for later runs.

The dataset is organized for `torchvision.datasets.ImageFolder`:

```text
landmark_images/
|-- train/
|   |-- 00.Haleakala_National_Park/
|   `-- ...
`-- test/
    |-- 00.Haleakala_National_Park/
    `-- ...
```

Each class directory contains images for one landmark. The training loader splits the training set into training and validation subsets; the separate `test` folder is used for final evaluation.

## Train and evaluate

Open and run either training notebook from top to bottom:

- `cnn_from_scratch.ipynb` trains the custom CNN in `src/model.py` and saves its best validation checkpoint as `checkpoints/best_val_loss.pt`. It exports a TorchScript predictor to `checkpoints/original_exported.pt`.
- `transfer_learning.ipynb` uses a pretrained ResNet50 with a new classifier head, then saves `checkpoints/model_transfer.pt` and exports `checkpoints/transfer_exported.pt`.

The notebooks include training, validation, test evaluation, and TorchScript export steps. The training functions automatically use CUDA when it is available.

## Run the image classification demo

After the transfer-learning notebook has created `checkpoints/transfer_exported.pt`, run `app.ipynb` from the repository root. Upload a landmark image, click **Classify**, and the notebook displays the image and its five highest-scoring class predictions.

The checkpoint files are not included in a fresh clone. Run the corresponding notebook to generate the checkpoint required by the demo.
